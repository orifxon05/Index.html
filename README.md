## 🚀 VERCEL GA JOYLASH (DEPLOYMENT GUIDE)

Vercel ga saytni 3 xil oson usulda joylashingiz mumkin:

### 1-Usul: GitHub orqali (Eng tavsiya etiladigan & professional)
1. **GitHub da yangi repozitoriy oching**: Masalan `orifxon-portfolio`.
2. Ushbu papkadagi fayllarni unga yuklang (push qiling):
   ```bash
   "C:\Program Files\Git\cmd\git.exe" init
   "C:\Program Files\Git\cmd\git.exe" add .
   "C:\Program Files\Git\cmd\git.exe" commit -m "feat: initial cybersecurity portfolio"
   "C:\Program Files\Git\cmd\git.exe" branch -M main
   "C:\Program Files\Git\cmd\git.exe" remote add origin https://github.com/orifxon05/orifxon-portfolio.git
   "C:\Program Files\Git\cmd\git.exe" push -u origin main
   ```
3. [Vercel.com](https://vercel.com) ga kiring (GitHub profilingiz bilan).
4. **"Add New..." -> "Project"** tugmasini bosing va `orifxon-portfolio` repozitoriyasini tanlang.
5. Sozlamalarni o'zgartirmasdan **"Deploy"** tugmasini bosing.
6. 10 soniyada saytingiz tayyor bo'ladi! Masalan: `https://orifxon-portfolio.vercel.app`.
